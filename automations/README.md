# Каталог `automations/` — Інструменти, Скрипти та Документація

Цей каталог призначений для спільних автоматизацій, скриптів, документації та інтеграції з **OpenClaw** для проєкту **SUBUNDERGRUND ELECTRONIC**.

> **Важливо для всіх розробників**:
> Каталог `automations/` є спільним і **не виключається** з Git-репозиторію (`.gitignore` його не блокує). Будь-які скрипти та документація для спільних завдань коммітяться сюди.

---

## 1. Конфігурація OpenClaw та Контекстне Вікно

Для важких обчислювальних задач (розрахунок DSP-формул, генерація вейвтейблів через ряди Фур'є, побудова складних пресетів, генерація AudioWorklet та прошивок мікроконтролерів) налаштовано локальний агент **OpenClaw**.

### Параметри активної моделі:
- **Модель**: `microsoft-foundry/grok-4.6` (провайдер `microsoft-foundry`, fallback з `gpt-5.3-codex`)
- **Розмір контекстного вікна**: **128 000 токенів** (128k)
- **Максимальний обсяг відповіді (`maxTokens`)**: **16 384 токени**
- **Рекомендований ліміт запиту (Safe Prompt Budget)**: до **100 000 токенів** (щоб залишався запас під генерацію та уникнення деградації/обрізання контексту).

## 2. Скрипти автоматизації

### `openclaw-runner.mjs` (Кросплатформний Node.js раннер)
Працює на Linux, macOS та Windows без додаткових залежностей (використовує нативний Node.js standard library).

**Особливості**:
- Автоматично оцінює кількість токенів у запиті (підтримує англійський текст, код та кирилицю).
- Попереджає або блокує запити, що перевищують безпечний ліміт 100k-118k токенів.
- Дозволяє передавати промпти через файл або аргумент командного рядка.
- Зберігає результат у файл або виводить у термінал.

**Використання**:
```bash
# 1. Швидка перевірка ліміту токенів без відправки запиту:
node automations/openclaw-runner.mjs --file path/to/large_dsp_task.txt --check-only

# 2. Виконання важкої задачі з текстового файлу:
node automations/openclaw-runner.mjs --file automations/tasks/generate-wavetables.txt --output src/audio/wavetables.json

# 3. Виконання прямого промпту:
node automations/openclaw-runner.mjs --prompt "Напиши DSP функцію для насичення сигналу (soft clipping tanh)"
```

### `run-openclaw.sh` (Bash обгортка)
Зручна обгортка для терміналів Linux / macOS:
```bash
./automations/run-openclaw.sh --prompt "Розрахуй коефіцієнти для biquad lowpass фільтра Баттерворта"
```
